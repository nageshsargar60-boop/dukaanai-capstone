# AI Development Workflow

## Before making changes
- Inspect the existing implementation and project instructions.
- Identify the files that need to change.
- Ask before making destructive changes or introducing new dependencies.

## While making changes
- Keep changes focused and consistent with the existing code.
- Do not invent features or claim tests passed without running them.
- Never expose or commit secrets.

## Before finishing
- Summarize the files changed and why.
- List the checks actually run and their results.
- Highlight any remaining issues or manual steps.
- Review the Git diff before committing.
